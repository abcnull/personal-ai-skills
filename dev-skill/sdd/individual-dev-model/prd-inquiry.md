# 找出需求存在的问题

## 概述

本文提供一种规范，需要你来找到用户需求文档中存在的多种问题。如果没有任何问题，你直接回复无问题即可

## 需求点不明确的问题

你需要分析整体需求，找出有没有存在需求理解上模糊不清的地方，有没有你无法理解的地方，如果有的话，你需要提出来，让开发者跟你解答

## 需求中存在逻辑矛盾的问题

你需要分析整体需求，找出需求中有没有前后矛盾，逻辑错误的地方，如果有，你需要提出来，让开发者订正或者解释

## 需求中存在的隐患或者漏洞问题

你需要分析整体需求，找出需求中有没有隐藏的隐患和漏洞，如果有，你需要提出来，让开发者补充需求细节或者解释

## 需求中的部分极端边界 case 的问题

你需要分析整体需求，找出需求中有没有极端边界 case 的问题，如果有，你需要提出来，让开发者补充需求细节
