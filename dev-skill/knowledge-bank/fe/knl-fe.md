# 前端整体技术栈情况
此文依赖作者的对前端的了解，结合了作者自身的技术栈，进行的前端整体技术栈被使用的行业标准情况的通用介绍

## 前端技术栈的标准应用

### vue 技术栈
企业级开发常见的内部用的后台管理系统的 web 前端：vue3 + vite + element plus + axios + vue-router

面向广大用户的后台管理系统（有自定义的样式风格）：vue3 + tailwind + shadcn-vue

需要快速原型（包含前后端），面向用户的应用交互型网站：nuxt + tailwind + nuxt ui/shadcn-vue + Supabase + vercel
